# Student levels by academic session

For multiple students, open Course Registrations and select a department. Optionally filter by current level or search text, then click Search. In Bulk session level update choose the historical session and level. Tick students or choose All students matching filters to include every page, then click Save bulk session level. Current profile levels remain unchanged. A conflicting result level stops the entire batch; correct the identified records or select a smaller group before retrying.

A student's current profile level is separate from their saved level for each academic session. Historical uploads do not promote or demote students.

1. Create the historical academic session and its course offerings, if missing.
2. Open Course Registrations, find the student, choose Edit Registration and load the historical session.
3. Select the student's level for that session and click Save session level. For example, save 100 for 2021/2022 and 200 for 2022/2023 while leaving their current profile at 500.
4. Register the student's courses for each semester in that session.
5. Upload the results with the corresponding session, semester and courses. Each row uses the student's saved session level, even if the worksheet course level differs (for example, a carryover).

Historical sessions require a confirmed level; the application does not calculate it by subtracting years from the current level. Repeated years and direct entry can therefore be recorded accurately. Current-session enrollment is initialized from existing profile levels when this feature is installed. Session activation preserves source and target levels, and approved promotions record the new level in the target session.

Students can open Course Registration, choose the historical session and click Load Session. The page shows their saved level for that session and offers its courses. Saving keeps the chosen session on the registration rather than using the globally active session. The registered-course history also links to registration for its selected session. Missing historical levels require administrator setup; registration-open and fee-clearance rules still apply.

Changing a saved level is blocked when existing results for the session have a different level. Existing result history is not silently rewritten. Result edits and group edits use the saved session level; reports continue to read the level retained on each result. Uploaded worksheet level metadata describes the course and does not override the student's historical level.
